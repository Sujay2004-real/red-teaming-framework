# Documentation index

These maintained guides describe release 4.0.0. The schema head is
`0006_framework`; source code and migrations remain authoritative for runtime
behavior.

- [Deployment](deployment.md): Docker/native setup, keys, networking and SSH.
- [API reference](api-reference.md): routes, authentication and request behavior.
- [Backend technical reference](backend_technical_reference.md): components,
  persistence and workflow.
- [Evidence upgrade](protected-evidence-upgrade.md): migration, protected
  originals and legacy reports.
- [Security controls](priority_security_fixes.md): enforced checks and practical
  limits.
- [Testing](testing.md): release verification commands and boundaries.
- [Frontend guide](../frontend/README.md): UI architecture and development.
- [Changelog](../CHANGELOG.md): release history.

Demo engagements, generated PDFs, presentations, evaluation fixtures and dated
project reports are intentionally excluded from the published repository. Keep
deployment-specific authorization letters and assessment evidence outside the
source tree.
